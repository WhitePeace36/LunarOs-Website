User guide

Short how-tos for getting the most out of LunarOs.

Gaming · 3 minutes

Make sure your game gets priority

Lunar gives games a higher CPU priority, a nice value of -5, so the Elara scheduler runs them before background tasks. This happens automatically for games that have a rule: Lunar's rules already cover more than 13,000 of them. If your game is missing, you can add it in a minute.

  1. Start your game

    Get into the game itself, not just the launcher. Some games start a separate process once you're past the menu.

  2. Check its nice value in Sysmon

    Press Ctrl + Shift + Esc to open Sysmon and switch to the Details tab. Press Ctrl + F and type part of the game's name. Look at the Nice column:

    Sysmon · DetailsCtrl+F: game
    NamePIDCPUNice
    RacingGame.exe4821331%-5
    SpaceGame.exe5190727%0

    Example with made-up game names.

    Nice is -5The game already has a rule. You're done.
    Nice is 0 or something elseThe game has no rule yet. Continue with step 3.

    Windows games running through Proton usually show up under their .exe name.

  3. Add the game in Ananicy Configurator

    Leave the game running and open Ananicy Configurator from the app menu. In the Types & Rules tab:

    • Click Add from running process…
    • Pick the game's process from the list. It's the same name you saw in Sysmon.
    • Choose Game as the type and click OK.

  4. Save and restart the service

    Click Save & Restart service. If it asks for your password, enter it. The rule applies to the running game within a few seconds, so you don't need to restart it.

  5. Check again

    Back in Sysmon, the game's Nice column should now show -5. From now on, the game gets priority every time you start it.

Good to know

  • Your rules are saved in /etc/ananicy.d. Lunar updates only replace the packaged rules, so your own rules are never overwritten.
  • Changed your mind? Select the rule in Ananicy Configurator and delete it, or use Reset to packaged for a packaged rule you edited.
