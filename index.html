LunarOs is Arch with a ready-to-use KDE Plasma desktop for gaming: its own linux-lunar kernel, the Elara sched_ext scheduler and system settings tuned for desktop play, set up from the first boot.

What you get

Install it, open Steam, play.

Lunar uses Arch's repositories for everything it doesn't change. What it does change is aimed at one thing: a fast, responsive gaming desktop with sensible defaults.

Performance

  • linux-lunar kernel in two builds: Clang ThinLTO for x86-64-v3 CPUs (Intel Haswell, AMD Zen and newer) and generic GCC for everything else. Arch's linux-lts as fallback.
  • Elara, a sched_ext CPU scheduler driven by the nice values ananicy-cpp sets from Lunar's rules.
  • zram swap, transparent huge pages, performance governor, per-disk I/O schedulers.
  • AMD cards run at their highest power limit with VRAM clock fixed at max.

Gaming, ready to go

  • Steam, Lutris, ProtonUp-Qt and MangoHud preinstalled.
  • Flatpak with Flathub and Flatseal, plus AppImageLauncher.
  • LibreWolf (with uBlock Origin) and Brave, both hardened out of the box.
  • OnlyOffice, LocalSend, Remmina, printing and scanning.

Desktop

  • KDE Plasma on Wayland, Breeze Dark across Plasma and GTK apps.
  • PipeWire with Pipewire Configurator and EasyEffects.
  • Sysmon system monitor on Ctrl+Shift+Esc.
  • zsh with lsd, bat, duf and micro.

Graphics

  • Mesa for AMD and Intel.
  • NVIDIA driver picked automatically: nvidia-open for Turing and newer, 580xx for Maxwell to Volta, nouveau for older cards.
  • Wayland-capable drivers only.

System

  • systemd-boot and Btrfs with subvolumes (ext4, XFS, F2FS too).
  • Optional full-disk encryption with LUKS2.
  • ufw firewall on by default.
  • lunar-chroot repair tool on the ISO.
Lunar's settings are made for desktop PCs. On a laptop they cost battery life, because the CPU, PCIe links, disks and sound chip don't enter their power-saving states.
Requirements

What your PC needs

Packages are downloaded during installation, so your system is up to date the moment it first boots.

UEFI

64-bit x86 PC booting in UEFI mode. Legacy BIOS isn't supported.

Secure Boot off

The boot loader and kernel aren't signed.

4GB / 40GB

Minimum RAM and disk space.

Online

An internet connection during installation, to download the newest packages.

Installation

Four steps to the moon

  1. Write the ISO to a USB stick

    Use balenaEtcher, Ventoy, or dd on Linux.

  2. Boot it in UEFI mode

    The live session starts KDE Plasma by itself.

  3. Connect and launch the installer

    Get online, then start Install LunarOs from the desktop.

  4. Follow the prompts

    Language, keyboard, disk, graphics driver, extra software and your user account. Done.

Illustration, not a benchmark. Turn on MangoHud in any game to see your own frame times.

Built to be fixed

When something breaks, boot the ISO and run one command.

lunar-chroot finds your installed system, mounts it with everything in its fstab (Btrfs subvolumes, LUKS, LVM, RAID and the EFI partition) and drops you into a root shell inside it.

Konsole — Lunar live USB
$ lunar-chroot
[root@lunar /]# <your fix>   example: pacman -Syu
[root@lunar /]# exit
